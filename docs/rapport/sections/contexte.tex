\section{Contexte et objectifs}
Ce projet construit un assistant agentique qui revoit un changement de code (diff ou pull request GitHub) et produit des constats structur\'es (bug, style, tests manquants, performance) avec s\'ev\'erit\'e, confiance et justification.

Les points durs sont la boucle d'agent (outils, it\'erations, sorties typ\'ees) et la parall\'elisation : un reviewer par fichier en parall\`ele, puis un agent juge qui fusionne, d\'edoublonne et \'ecarte les constats \`a faible confiance.
