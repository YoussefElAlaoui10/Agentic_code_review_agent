\section{Environnement de test des agents}
Consigne du professeur : disposer d'un environnement permettant de tester les capacit\'es des agents.

\begin{itemize}
  \item 2 \`a 3 bases de code de langages diff\'erents (Rust, TypeScript, JavaScript) et de projets diff\'erents (par exemple un moteur de jeu vid\'eo), de taille raisonnable, structur\'ees, avec README et documentation ;
  \item possibilit\'e de revenir \`a un \'etat ant\'erieur sain du projet ;
  \item variantes d\'egrad\'ees : documentation supprim\'ee et <<~trous~>> emp\^echant le projet de fonctionner ;
  \item pull requests contenant des bugs connus et \'etiquet\'es, que l'agent doit d\'etecter.
\end{itemize}

\emph{\'Etat : \`a r\'ealiser. Aucune cible n'est encore choisie.}
